# Updates of 09/11/2026 (client points of 06 to 09/11)

**Bulk orders: more packages for one receiver.** A receiver with more bags no longer has to be entered again as a new receiver. In the
business portal's bulk order each card is a receiver ("Receiver 1, 2…", "Add a receiver" below) with "Add another package": each
package has its agreed size and its contents. The receiver is one order with a label per package, priced at each package's agreed rate
(`row.more`, `store.batchOrder`). Spreadsheet lines for the same receiver (Excel import and the office's New bulk order: same name,
number, delivery method and address) become one order with a package per line; their cash to collect adds up and their references are
kept (`sameReceiver` in `store.createBatch`). The bulk pages, the driver's bulk collection, the collector's message and the labels
count packages.

**Taken out: "Add a package" on a bulk order already made** (05/11/2026, `store.addToBatch`): no change was wanted there.

**Photos on the link we send.** The link of a bulk package now shows the driver's photo of the bulk collection (it belongs to the bulk
order, not to one package; `api/track.js` also reads the files the order points to that belong to no order). On the live service every
photo on the link showed as a grey "PDF" tile, because the page drew a picture only for a photo kept inside the page and live photos
are signed links. It shows the picture now, for every order, and opens it in a new tab.

**Shop & Deliver: a sample photo per item.** "Add a sample photo" under each item to buy, optional, on the customer's form and the
office's new order (`details.items[].photoId`, file kind `item_photo`). The driver has "Photo: <item>" with the job's files, the office
sees it next to the item and among the order's photos, and the link we send shows it.

**Numbers from abroad.** A customer's own number (the request form, the office's new order, the e-store) may be a foreign WhatsApp or
Viber number: + (or 00) and the country code, for example +44 7700 900123. A number of 7 digits without a country code is still read as
Maldivian, so local numbers are entered as before. Receiver and contact numbers already took numbers from abroad.

Tests: demo `tools/_scratch/r11-client.js`; live `tools/supabase/test-r11.js`, test-live section 3.
